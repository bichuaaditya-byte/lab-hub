# Aaditya's Lab Hub v2

## Rename a subject
Edit `config.js` and change the `name` value.

## Experiments
Every subject has 15 ready-made experiment slots. Each page includes Aim, Theory, Code, Copy Code, screenshot placeholders, and Result.

For permanent screenshots on GitHub Pages, put image files inside the experiment folder and add an image tag such as:
`<img src="output.png" alt="Output screenshot">`

Upload the whole folder to GitHub and enable GitHub Pages under Settings → Pages.
